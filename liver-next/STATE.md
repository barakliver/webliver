## הבדיקות

```bash
npm run check      # typecheck, 121 טסטים, classes, bidi, contrast
npm run build
npm run verify     # בשרת: 38 בדיקות מול האתר שרץ
```

`npm run lint` נמחק. הוא הריץ `next lint` שכבר לא קיים, ולא נכשל בצורה שמישהו
מזהה כחוסר בלינטר, אלא דיווח שתיקייה בשם lint לא קיימת.

שלוש בדיקות נולדו משלוש תקלות אמיתיות שלא רואים בקוד ולא רואים במסך:

- **`classes`** מוצאת מחלקת צבע שלא מייצרת הצהרה. `border-accent/40` נראה תקין
  ולא צייר כלום, כי Tailwind לא מוסיף שקיפות למשתנה שמחזיק צבע שלם. שלושים
  ושלוש הצהרות נמחקו כך בשקט
- **`bidi`** מוצאת סכום או יחס שנבנה ביד. `2/5` בשורה עברית מתהפך ל‑`5/2`
- **`contrast`** פוסלת גוון שנופל מתחת לתקן. שלושה הוכהו לפני שנכנסו

וב‑Supabase: `supabase/verify.sql`. קורא בלבד.
