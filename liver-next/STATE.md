## הדבר הראשון לעשות מחר

**לוודא איזה קוד רץ בשרת:**

```bash
cd "$(systemctl show liver-next -p WorkingDirectory --value)" && git log --oneline -1
```

אם זה לא `b400505` או חדש יותר, הפריסה היא:

```bash
cd ~/webliver
git status --short          # צריך להיות ריק
git fetch origin
git checkout -B claude/general-fixes-kqxoqc origin/claude/general-fixes-kqxoqc
cd liver-next
npm ci                      # חובה — נוספה תלות חדשה
npm run build               # אם נהרג בזיכרון, צריך swap
systemctl restart liver-next
npm run verify              # 20 בדיקות
```

`.env.local` לא בגיט ולא ייגע.

## שאלה פתוחה עם משתמש אמיתי

**"ניסיתי להיכנס עם מייל אחר, הוא לא נותן."** לא נסגר.

שתי סיבות אפשריות, ופקודה אחת מפרידה ביניהן:

```bash
journalctl -u liver-next -n 80 --no-pager | grep -i auth
```

- **יש `[auth] signInWithOtp failed`** → שרת המייל של Supabase חוסם. הוא מוגבל
  לכשתי הודעות בשעה ובפועל מסרב לכתובות שאינן חברות בארגון. התיקון הוא SMTP
  משלך, לא קוד.
- **אין שורה כזו** → הכניסה הצליחה והמשתמש נחת על "החשבון ממתין לאישור". זו
  ההתנהגות שנבנתה בכוונה. זוג נכנס רק אחרי שצירפו את המייל שלו בתוך אירוע;
  מפיק נכנס רק אחרי אישור בקונסול.

1. חנות והזמנות — הטבלה קיימת, המסך לא

וספקים, עורך תוכן לאתר, עוזר דיגיטלי.
